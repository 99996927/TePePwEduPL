# 12. Słownik pojęć

| Pojęcie | Znaczenie |
|---|---|
| Agent | Moduł AI korzystający z Claude (Anthropic API), który odpowiada na pytania i przygotowuje szkice korekt przez wywołania narzędzi. |
| Tool use | Mechanizm, w którym model wybiera narzędzie, a aplikacja je wykonuje i zwraca wynik. |
| Silnik reguł płacowych | Deterministyczna biblioteka bez I/O, jedyne źródło liczb w systemie. |
| Okres rozliczeniowy | Okres, w którym uśrednia się normy czasu pracy (do 4 miesięcy, w uzasadnionych przypadkach do 12). |
| Godziny nadliczbowe | Praca ponad obowiązujące normy czasu pracy (art. 151 § 1 Kodeksu pracy). |
| Odpoczynek dobowy / tygodniowy | Co najmniej 11 h dziennie i 35 h tygodniowo nieprzerwanego odpoczynku (art. 132, 133). |
| Zmiana płacowa | Zmiana stawki lub składnika wynagrodzenia konkretnego pracownika (z datą obowiązywania i uzasadnieniem), wymagająca zatwierdzenia przez dwie różne osoby. |
| Zasada czterech oczu | Zatwierdzający musi być inną osobą niż autor zmiany. |
| Szkic korekty | Propozycja korekty wpisu czasu pracy przygotowana przez agenta, niezmieniająca danych do czasu zatwierdzenia przez człowieka. |
| Kadry | Dział kadr: role `HR` (przygotowuje) i `HRApprover` (zatwierdza). |
| ELI | European Legislation Identifier, interfejs API Sejmu do aktów prawnych. |
| Dz.U. | Dziennik Ustaw. |
| ADR | Architecture Decision Record, zapis decyzji architektonicznej. |
| UC-xx | Identyfikator przypadku użycia, używany także w nazwach testów E2E. |
